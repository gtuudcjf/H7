## 独立审阅修复

一名独立审阅者发现四项 Important，均已加入失败复现并修复：

1. TIM8 CH4 的 HAL PWM Start 也会置位 MOE；新增与 TIM6 关断序列化的许可检查。
2. 三帧零命令准备不能跨 Enabled 命令累积。
3. 前台恢复时先收帧、后 Poll，不能用新帧覆盖已过期的 READY 心跳。
4. HAL 停机失败不能清掉待清理标志；复位必须实际重试清理成功。

同根因补测：启动过程后续步骤和回滚都失败时，也必须保留待清理状态。

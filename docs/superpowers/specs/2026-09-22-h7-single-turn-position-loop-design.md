# H7 单圈轴侧位置环设计

## 目标与边界

在已经实机验证的编码器角度电流模式（模式 3）和编码器速度电流模式（模式 4）之外，新增可独立选择的轴侧位置模式。位置模式使用同一只 17 位 BiSS 单圈绝对编码器；控制链为机械位置 P 环 → 现有速度 PI 环 → 现有 10 kHz 电流 PI 环。模式 3 和模式 4 的命令、增益、限幅及运行路径保持不变。这里的“独立运行”指模式可分别选择，不指位置控制绕开必要的内环。

电机轴已确认可双向自由旋转，且无机械限位、缠线或单向接近要求。本阶段仅控制**电机轴**在一圈内的角度，不提供负载轴闭环、累计多圈定位、断电圈数保持或轨迹规划。

## 已有工程依据

- `biss_frame.h` 定义 17 位、每圈 131072 计数；`encoder_angle.c` 已将校准零点和方向应用到 `mechanical_angle_pu`，其范围为 `[0, 1)`。位置反馈沿用这一路，不另建编码器采集通道。
- `motor_control.c` 中 `MotorControl_RunSpeedTask()` 以 1 kHz 更新速度估计、速度 PI 和目标 `Iq`；ADC 注入回调以 10 kHz 执行电流 PI。位置计算与速度任务同频，先计算速度目标，再调用原速度 PI。
- 当前速度 PI 参数为 `Kp=0.03 A/rpm`、`Ki=0.015 A/(rpm·s)`、`Kaw=10 /s`，速度环 `Iq` 上限为 0.7 A，速度模式电流目标斜率为 10 A/s。现有 `50 rpm` 速度模式不因位置模式而改值。
- 已有 `MOTOR_SPEED_COMMAND_SLEW_RPM_PER_S=20 rpm/s`。位置模式复用此斜率，避免目标角度更新造成速度参考阶跃。

## 方案选择

采用独立的纯计算 `PositionController`（P 控制），输出受限的机械速度目标，再复用速度 PI。首版不加位置积分：静止保持所需的 `Iq` 由内层速度 PI 生成；外层积分会使越圈误差、速度饱和和静摩擦下的调试更复杂。也不采用位置误差直接输出 `Iq`，因为那会绕过已有的速度约束。

## 角度语义与初始参数

- 公共目标使用**电机轴机械角度**，单位度，取值 `[0, 360)`；零点为现有编码器校准记录的 `electrical_zero_raw` 对应的机械位置。它不是设备外壳或负载轴的独立机械零点。
- 反馈角度由 `encoder_angle_sample.mechanical_angle_pu * 360` 得到。误差为目标减反馈的环形最短差，范围 `(-180, 180]` 度；恰好相差 180 度时固定选择正方向。359 度到 1 度应得到 `+2` 度，而不是 `-358` 度。
- 首次实机验证建议位置 P 增益 `0.4 rpm/度`、位置模式速度上限 `20 rpm`、位置容差 `0.5 度`。`|误差| <= 0.5 度` 时速度目标置 0；超出时 `速度目标 = clamp(Kp × 误差, -20, +20) rpm`。这是保守起点，不代表已验证的定位精度或稳定性。
- 对位置模式新增的增益、速度限幅和容差均集中在 `motor_params.h`，运行前检查有限值及合理范围。位置模式不得放宽原有 `Iq=0.7 A` 上限、电流斜率或保护阈值。

## 模式、命令与状态

- 在 `MotorControlMode` 中增加独立位置模式。保留现有枚举数值，特别是不改变 `MOTOR_CONTROL_FAULT` 的数值；新模式使用单独的新数值。`main.c` 默认仍为模式 4，不能因为加入位置模式而使上电直接转向某个预置角度。
- `MotorControl_RequestMode(position)` 沿用现有模式请求与 10 kHz 边界切换机制，要求电流采样就绪、编码器校准有效且有新鲜有效的编码器帧；编码器过期沿用现有故障处理。
- 进入位置模式时，无论是上电选择还是从其他模式切入，都先读取当前机械角度作为目标并保持。旧的位置命令不跨模式自动重放。只有位置模式已运行后，显式调用 `MotorControl_SetPositionCommand(float target_deg)` 才开始定位；无效角度或非位置运行状态返回错误，不改变目标。提供与现有模式切换风格一致的无目标参数切换接口。
- 位置模式使用 `MotorControl_ModeUsesSpeedLoop()` 的已有速度估计、PI 预装载、`Iq` 斜率和限幅路径；仅在位置模式分支将位置 P 输出送入该速度路径。模式 4 继续使用自己的 `speed_target_rpm`，切出位置模式时清除位置状态，不影响模式 3 的直接 `Iq` 命令。
- 在稳定调试结构中新增位置目标、反馈、最短误差、位置输出速度以及位置控制就绪标志。现有调试字段含义不变。

## 故障与安全

编码器无效、校准缺失、控制计算结果非有限值时，不输出未知角度或新转矩命令；沿用现有拒绝模式请求或锁存故障/停机路径。位置命令不允许在启动、校准、停止或故障状态悄悄排队到下次启动。不得通过位置环新增裸 PWM 或直接电流输出。单圈最短路径只适用于已确认的自由旋转电机轴；若机械系统改变为有限位结构，必须重新设计路径规划。

## 改动范围

- 新增 `Core/Inc/motor/position_controller.h` 与 `Core/Src/motor/position_controller.c`：纯数学控制、参数验证、环形误差、限幅和容差，无 HAL 依赖。
- 扩展 `motor_runtime_policy.h/.c`、`motor_control.h/.c`：新增模式、API、控制状态、调试字段和模式切换分支。
- 扩展 `motor_params.h`：仅增加位置参数；`main.c` 仅增加模式说明和示例命令说明，不改变默认运行模式或现有环参数。
- 更新 Keil 项目源文件列表；新增位置控制单元测试与模式集成测试。避免修改无关的驱动、ADC、PWM、编码器帧解析及现有模式算法。

## 验收与实机验证

1. 单元测试覆盖 0 度越界、359→1 度、1→359 度、±180 度、容差、输出限幅和非法参数。
2. 集成测试覆盖位置模式识别/许可、上电及模式切入时保持当前位置、显式命令才移动、模式 3/4 路径未改、编码器失效保护。
3. 运行现有全部工程检查与主机单元测试，并用 Keil 完整编译，要求 0 错误。测试生成文件不得纳入提交。
4. 实机先空载、低电流确认方向与越零点行为，再以小角度阶跃观察 `position_error_deg`、`speed_filtered_rpm`、`speed_iq_command_a`、`iq_a`、故障与饱和标志。仅通过静态测试和编译不能声称实机位置环稳定。

# H743 编码器速度电流闭环设计

## 1. 目标

在现有 STM32H743 电机控制工程中新增第四种控制模式：

```c
MOTOR_CONTROL_ENCODER_SPEED_CURRENT
```

该模式使用电机轴上的 17 位 BiSS-C 绝对值编码器估算机械转速，以速度 PI
产生 `Iq_ref`，再复用已经实机验证的编码器电角度电流内环。前三种模式的
控制含义和时序保持不变。

本阶段不实现位置环、不实现自动参数辨识，也不把减速器输出轴速度作为控制量。
所有速度命令、反馈和调试量均表示电机轴机械转速，单位为 rpm。

## 2. 现有基础与 F407 代码结论

H743 工程已有以下可复用基础：

- 10 kHz TIM8 快速控制边界；
- 10 kHz ADC 注入完成回调中的电流采样、电流 PI、SVPWM 和 PWM 更新；
- SPI4 DMA 非阻塞编码器采集和一致快照；
- 17 位机械位置、电角度零点、方向和极对数校准；
- 模式 3 `MOTOR_CONTROL_ENCODER_ANGLE_CURRENT`，可直接给定 `Id/Iq`；
- 电流命令斜坡、联合电压限幅、抗积分饱和和故障关断。

F407 原工程的控制链 `get_speed -> speed LPF -> speed PID -> currentloop`
可作为功能参考，但其实现不直接移植，原因如下：

- `coff_speed = 5.49` 没有显式编码器分辨率和采样周期依据；
- 64 点移动平均与隐含调用频率绑定；
- `Ki = 0.0005` 是每次调用的离散增量，不具有明确的时间单位；
- PI 参数在每次调用时重复写入；
- `Iq` 输出限幅为 `±6 A`，超过当前 H743 首次调试的安全范围；
- 通用 PID 的历史误差更新和抗积分饱和不适合直接沿用。

因此新实现保留级联控制思想，按照当前 H743 电流环的模块化、显式单位、
显式周期和主机侧单元测试方式重写。

## 3. 总体控制结构

```text
17 位编码器位置快照
        |
        v
跨零差分、方向修正、按实际周期换算
        |
        v
机械速度原始值 rpm -> 一阶低通 -> 机械速度反馈 rpm
                                      |
目标速度 rpm -> 命令斜坡 ------------(-)
                                      |
                                      v
                         1 kHz 速度 PI + 抗积分饱和
                                      |
                                      v
                          Iq_ref，限制在 ±0.6 A
                                      |
                                      v
              现有 10 kHz 电流 PI -> SVPWM -> TIM8 PWM
```

速度估算在使用编码器的模式 3和模式 4中都运行，便于先在模式 3验证速度符号
和量级；速度 PI 仅在模式 4运行。速度模块不直接访问 HAL、SPI、ADC 或 PWM。

## 4. 模块边界

### 4.1 `speed_estimator.h/.c`

该模块是无 HAL 依赖的纯算法模块，职责包括：

- 接受 17 位原始位置、新帧序号、编码器校准方向和实际采样周期；
- 使用 `[-65536, 65535]` 最短路径计算跨零位置增量；
- 在原始位置增量上应用已校准方向，使正速度与正 `Iq` 的约定一致；
- 按下式换算电机轴机械转速：

  ```text
  raw_rpm = directed_delta_count * 60 / (131072 * sample_period_s)
  ```

- 用基于截止频率和实际周期计算系数的一阶低通得到滤波速度；
- 只有帧序号变化时才产生新速度样本，重复快照不能被解释为零速度；
- 首个位置样本只建立基准，第二个新样本到达后才置 `ready`。

零点偏移不参与速度差分，因为它不改变速度；编码器方向必须参与速度符号修正。

### 4.2 `speed_pi.h/.c`

该模块同样无 HAL 依赖，使用具有物理单位的参数：

- `Kp`：A/rpm；
- `Ki`：A/(rpm·s)；
- `Kaw`：1/s；
- 输出：`Iq_ref`，单位 A。

控制器采用 PI 和回算式抗积分饱和。模块提供初始化、单步计算、复位、输出预装载、
在线修改增益和在线修改输出限幅接口。所有参数、输入、周期和内部状态必须拒绝
NaN、Inf 和非法范围。

### 4.3 `motor_control.c`

组合层负责：

- 以 10 kHz 快速边界计数，每 10 次调度一次 1 kHz 速度任务；
- 将编码器一致快照交给速度估算器；
- 在模式 4中执行目标速度斜坡和速度 PI；
- 把速度 PI 输出接到现有编码器角度电流环的 `Iq_ref`；
- 处理模式进入、退出、停机、故障和调试快照。

ADC 注入完成回调仍是电流 PI 和 PWM 写入的唯一闭环快速执行点。速度环不得直接
写 TIM8 CCR，也不得在中断中执行阻塞式 SPI 读取。

## 5. 调度与数据一致性

- 电流环周期：`100 us`，即 10 kHz；
- 速度环周期：`1 ms`，即 1 kHz；
- 速度任务由现有快速边界分频，不增加新的硬件定时器；
- 速度估算只消费序号发生变化的完整编码器快照；
- 编码器帧过期继续使用现有 `MOTOR_FAULT_ENCODER_STALE` 关断路径；
- 速度任务未到期时，电流环保持上一周期的速度 PI 输出；
- 速度估算器尚未 `ready` 时不得执行速度 PI。

固定 `1 ms` 任务周期下，17 位编码器一计数对应约 `0.458 rpm` 的单周期速度量化。
一阶低通用于抑制该差分噪声，而不是使用与调用周期隐式绑定的 64 点数组。

## 6. 模式定义与接口

`MotorControlMode` 新增：

```c
MOTOR_CONTROL_ENCODER_SPEED_CURRENT
```

新增公共接口：

```c
void MotorControl_SetSpeedCommand(float mechanical_speed_rpm);

HAL_StatusTypeDef MotorControl_SwitchToEncoderSpeedCurrent(
    float mechanical_speed_rpm);

HAL_StatusTypeDef MotorControl_SetSpeedPiGains(
    float kp_a_per_rpm,
    float ki_a_per_rpm_s,
    float kaw_per_s);

HAL_StatusTypeDef MotorControl_SetSpeedIqLimit(float iq_limit_a);
```

`.mode` 继续作为上电模式的唯一选择项。启动前可分别预设各模式的命令；选择模式 4
后使用速度命令，其余模式命令保持但不参与当前输出。首次合入不主动把 `main.c` 的
默认模式改成模式 4，避免烧录后出现未经确认的主动转动。

模式 3和模式 4的区别仅是 `Iq_ref` 来源：

- 模式 3：上层直接给定 `Id/Iq`；
- 模式 4：固定 `Id_ref = 0`，由速度 PI 生成 `Iq_ref`。

## 7. 模式切换与初始状态

进入模式 4前必须满足：

- 电流采样校准完成且反馈有效；
- 编码器校准记录有效；
- 编码器已有新鲜、有效的一致快照；
- 当前不处于编码器校准、保存或故障流程。

从停止状态直接启动模式 4时：

1. 完成现有电流零偏校准；
2. 等待编码器新鲜快照；
3. 速度估算器取得首个基准位置；
4. 第二个新位置样本到达前保持 `Iq_ref = 0`；
5. 估算器就绪后，从当前反馈速度向目标速度执行命令斜坡；
6. 速度 PI 从零输出开始工作。

从模式 3切入模式 4时：

- 当前电流内环继续运行；
- 速度估算器取得两个新样本前保持当前有效 `Iq_ref`；
- 估算器就绪后，将速度 PI 输出预装载为当前有效 `Iq_ref`；
- 速度目标从当前反馈速度按斜坡走向请求值，降低转矩跳变。

退出模式 4时复位速度 PI 和速度模式内部状态。切到模式 3时，现有电流参考斜坡从
最后一个速度 PI 输出平滑走向模式 3命令；切到开环模式时沿用现有电压过渡策略。

`0 rpm` 表示主动零速调节，不等同于关断功率级；安全停机仍必须调用
`MotorControl_Stop()`。

## 8. 首版参数

参数集中放入 `motor_params.h`，并明确标注换电机、编码器安装位置、负载或减速器后
需要重新验证：

```c
#define MOTOR_SPEED_CONTROL_PERIOD_S        (0.001f)
#define MOTOR_SPEED_CONTROL_DIVIDER         (10U)
#define MOTOR_SPEED_COMMAND_LIMIT_RPM       (100.0f)
#define MOTOR_SPEED_COMMAND_SLEW_RPM_PER_S  (20.0f)
#define MOTOR_SPEED_FILTER_CUTOFF_HZ        (20.0f)

#define MOTOR_SPEED_PI_KP_A_PER_RPM         (0.005f)
#define MOTOR_SPEED_PI_KI_A_PER_RPM_S       (0.10f)
#define MOTOR_SPEED_PI_KAW_PER_S            (10.0f)
#define MOTOR_SPEED_IQ_LIMIT_A              (0.6f)
```

这些值是保守的首次上机参数，不宣称是最终整定结果。速度 PI 的 `Iq` 限幅还必须受
全局 `MOTOR_CURRENT_COMMAND_LIMIT_A` 限制，任何在线限幅接口都不能突破全局电流
安全边界。

## 10. 故障与边界处理

- 无效配置、NaN、Inf、零或负周期必须被拒绝；
- 速度算法内部出现非有限数值时进入现有 `MOTOR_FAULT_CONTROL_MATH`；
- 编码器无效、CRC、帧状态和过期故障沿用现有编码器保护；
- 重复编码器序号不会生成假零速，也不会重复积分速度 PI；
- 停机和故障必须复位速度估算器、速度 PI、分频计数和就绪标志；
- 首版不新增堵转和超速故障，依靠 `±0.6 A` 转矩限幅及现有过流保护完成低速调试；
- 未经实机验证前不得提高目标速度或 `Iq` 限幅。

## 11. 测试策略

### 11.1 主机侧单元测试

速度估算器至少覆盖：

- 静止、正转和反转；
- 17 位正向、反向跨零；
- 编码器方向修正；
- 首帧未就绪和第二帧就绪；
- 重复序号不更新；
- 一阶低通收敛；
- 非法位置、方向、截止频率和周期被拒绝。

速度 PI 至少覆盖：

- 零误差和比例响应；
- 按秒积分而非按调用次数隐式积分；
- `±0.6 A` 对称限幅；
- 长时间饱和时积分器有界；
- 输出预装载后的无冲击首步；
- 复位和非法参数处理。

模式与集成测试至少覆盖：

- 模式 4被识别为已实现的编码器电流控制模式；
- 模式 4需要电流反馈、编码器就绪和有效校准；
- 速度任务仅每 10 个快速周期运行一次；
- 模式 4使用编码器电角度，并最终进入现有电流 PI；
- 前三种模式的既有测试继续通过；
- Keil 工程包含两个新模块并实现 0 error、0 warning 构建。

## 12. 实机验证顺序

由于减速器静摩擦使电机无法手动转动，速度方向验证改为主动低转矩测试：

1. 保持模式 3，设置 `Id = 0`，从 `Iq = +0.2 A` 开始；
2. 若静摩擦未克服，以 `0.1 A` 为步长增加，但不超过已验证的 `+0.6 A`；
3. 观察 `speed_raw_rpm`、`speed_filtered_rpm` 和编码器位置变化，确认正 `Iq` 对应正 rpm；
4. 停稳后用负 `Iq` 做对称验证，仍不得超过 `-0.6 A`；
5. 如果速度符号相反，先检查编码器校准方向和相序，不通过修改 PI 符号掩盖问题；
6. 切换模式 4，先设置 `0 rpm`，确认无明显抖动或持续电流饱和；
7. 依次测试 `+5、+10、-5、-10 rpm`；
8. 再测试 `±20 rpm`，观察速度误差、积分项、`Iq_ref` 和饱和标志；
9. 确认稳定后逐步放开到 `±100 rpm`；
10. 只有反馈正确且不持续限流时，才调整 `Kp/Ki` 或提高 `Iq` 限幅。

编码器安装在电机轴，因此上述 rpm 均为电机轴转速。如果将来上层需要减速器输出轴
rpm，应由上层使用已知减速比换算，不改变底层速度估算器的物理定义。

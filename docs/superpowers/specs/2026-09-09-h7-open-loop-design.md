# H7 开环电机控制设计

## 目标

在现有 STM32H743 `emptytest` CubeMX/MDK 工程中加入可运行的三相开环电压控制。控制输出使用既有 TIM8 的三对互补 PWM；当前不接入 BKIN，也不接入 ADC 电流闭环、编码器反馈或速度环。

## 约束

- 保留 CubeMX 生成的 `Core/Inc`、`Core/Src`、`MDK-ARM` 工程框架。
- TIM8 的现有引脚、定时器频率和 CubeMX 配置不由应用代码重写。
- 功率级默认禁能；只有调用启动接口才启动 TIM8 的三对主/互补 PWM。
- 不配置或假设 BKIN 硬件；停止通过关闭 PWM 输出完成。
- 所有快速控制计算不得调用阻塞 SPI、UART 或 `HAL_Delay`。
- 使用标幺电角度 `[0, 1)`，电压命令使用归一化幅值，避免将旧 F407 的固定母线电压比例和 PWM 计数迁入 H7。

## 架构

新增代码位于 `Core/Inc/motor` 与 `Core/Src/motor`：

1. `svpwm` 是纯算法模块。输入 d/q 电压和标幺电角度，输出三相 `[0, 1]` 占空比，不知道 TIM8 或 HAL 的存在。
2. `open_loop` 管理幅值、目标电角频率、斜坡和相角积分；每次快速调用产生一个 d/q 命令。
3. `pwm_3ph` 是 TIM8 硬件适配层，负责启动、停止和把占空比写入 CCR。它不包含 SVPWM 算法。
4. `motor_control` 组合前三层。`MotorControl_FastTick()` 是唯一快速入口；开环时调用开环发生器、SVPWM 和 PWM 适配层。未来电流环替换 d/q 命令来源，速度环只更新 Iq 参考，不改变 PWM/SVPWM 接口。

## 运行时序

`main()` 完成 CubeMX 外设初始化后初始化电机模块，设置低电压、低频率开环命令并显式启动。主循环根据固定的控制步长调用 `MotorControl_FastTick()`；该步长先以软件时间基准提供，后续可改为 TIM8 更新中断而不用改变控制模块接口。

## 安全策略

- 初始化与停止时均把三相占空比设为 50%，再关闭 PWM 主/互补输出。
- 输入电压幅值限制在安全的线性调制范围内；输出占空比始终限制为 `[0, 1]`。
- 方向由频率正负决定；相角统一环绕到 `[0,1)`。
- DRV8323 使能脚和 SPI 配置尚未确认其对应 H7 管脚，本阶段不臆测 GPIO 定义。PWM 模块只负责 MCU 输出。

## 验证

在宿主机上编译纯算法单元测试：验证零矢量占空比、相角环绕、斜坡方向和 SVPWM 输出边界。目标板验证顺序为：未接母线确认停止状态，再确认 PWM 波形和互补关系，最后以受限母线电压和低频率带电测试。

# H7 编码器角度反馈电流闭环设计

日期：2026-09-11
目标工程：STM32H743 + DRV8323 + TIM8 六路互补 PWM + AksIM-2 17 位 BiSS-C 编码器

## 1. 目标与术语

本阶段在已经通过实机验证的 H7 工程上新增“编码器角度反馈、Id/Iq 电流闭环”模式。该模式使用减速前电机轴编码器提供真实转子电角度，使 Park、反 Park 和电流 PI 工作在真实转子坐标系中。

本阶段不实现机械位置控制器，也不实现速度 PI。这里的“角度反馈”仅表示编码器电角度参与 FOC 坐标变换，不计算目标角度与实际角度之差，不输出位置控制量。

已有模式必须继续独立可用：

- 电压开环：虚拟电角度 + 给定 `Ud/Uq`。
- 角度开环、电流闭环：虚拟电角度 + `Id/Iq` 电流 PI。
- 编码器角度反馈、电流闭环：真实编码器电角度 + `Id/Iq` 电流 PI。

后续速度环只在本电流环外增加速度估算和速度 PI，并通过现有 `Iq_ref` 接口给出转矩电流指令，不重写本阶段的电流控制核心。

## 2. 已确认的硬件与协议

- 减速前电机轴编码器连接 `ENC_01 / SPI4`。
- SPI4 引脚：PE2/SCK、PE5/MISO、PE6/MOSI。
- 编码器采用 17 位单圈 BiSS-C，机械位置范围为 0～131071。
- BiSS-C 帧含 13 位 ACK、Start、CDS、17 位位置、Error、Warning 和 6 位反相 CRC。
- 编码器位置为 MSB 先发送，CRC6 多项式为 `0x43`。
- MA 时钟空闲为高，第一个下降沿发起通信；编码器在上升沿更新 SLO，控制器应在下降沿采样。
- 电机极对数为 10。
- SPI3/ENC_02 为减速后编码器接口，本阶段不启动、不参与控制，但通用驱动接口应允许后续增加第二实例。

完整原理图确认，数据通道 U18/MAX14783 的 `DE` 和 `/RE` 固定接低：差分发送器永久关闭，差分接收器永久开启。`ENC_TX_01` 经隔离器连接 U18 的 DI，但由于 DE 固定为低，该信号不会驱动编码器数据线，也不承担收发方向控制。只读位置时 PE6 配置为 GPIO 推挽输出并持续输出低电平，避免无意义翻转；SPI4 物理通信只使用 PE2 时钟和 PE5 返回数据。

时钟通道 U28/MAX14783 为固定发送结构，PE2/SPI4_SCK 经 U27 数字隔离器和 U28 转换为 `ENC_CLK_01` 差分时钟；返回数据经 U18 和 U16 转换为 PE5/SPI4_MISO。因此现有硬件能够实现“SPI外设产生 BiSS-C MA 时钟、MISO采集 SLO”的只读通信。

## 3. 控制模式与兼容性

控制模式语义为：

```c
typedef enum
{
    MOTOR_CONTROL_STOPPED = 0,
    MOTOR_CONTROL_OPEN_VOLTAGE,
    MOTOR_CONTROL_OPEN_ANGLE_CURRENT,
    MOTOR_CONTROL_ENCODER_ANGLE_CURRENT,
    MOTOR_CONTROL_FAULT
} MotorControlMode;
```

若已有代码使用 `MOTOR_CONTROL_ENCODER_CURRENT`，则保留等值兼容别名，避免破坏现有调用方。

模式之间复用现有 `current_sense`、`foc_transform`、`current_pi`、`svpwm`、`pwm_3ph` 和 DRV8323 适配层。不得为编码器模式复制另一套电流 PI 或 SVPWM。

进入编码器电流模式必须满足：

1. 电流偏置校准已经成功。
2. 编码器通信已连续获得足够数量的有效帧。
3. 已存在通过 CRC 校验的电角度校准参数。
4. 编码器最新有效数据未超时。

任一条件不满足时拒绝切入编码器模式，已有开环模式仍可继续使用。模式请求仅在控制周期边界消费，不允许主循环、调试器或通信代码直接写 TIM8 CCR。

## 4. 软件模块

新增模块按以下职责拆分：

### 4.1 `biss_encoder`

- 绑定 SPI 句柄和收发器方向 GPIO。
- 使用 SPI4 TX/RX DMA 启动非阻塞帧读取。
- 保存每个实例独立的收发缓冲区和忙状态。
- 从完整原始帧识别 ACK、Start 和 CDS。
- 提取 17 位位置、Error、Warning 和 CRC6。
- 只有帧结构、状态和 CRC 满足要求时才发布新位置。
- 统计有效帧、CRC 错误、帧错误、SPI 错误、忙冲突和超时。
- 提供最近有效位置、序号和时间戳的快照接口。

解析函数必须与 HAL 解耦，允许主机侧直接输入固定字节数组做单元测试。不得沿用 F407 中固定右移 6 位且不校验 CRC 的解析方法。

### 4.2 `encoder_angle`

- 将 17 位原始位置换算为 0～1 pu 机械角。
- 集中处理编码器方向、电角度零位和 10 对极换算。
- 生成 0～1 pu 电角度。
- 为后续速度估算保留机械角快照和跨零增量接口。

### 4.3 `encoder_calibration`

- 实现按需触发的转子对齐状态机。
- 只在电机停止、编码器有效和电流采样就绪时运行。
- 使用受限的正向 `Id` 和零 `Iq` 对齐转子。
- 对稳定区间内的编码器位置做环形平均。
- 校验方向、稳定度和超时。
- 成功后产生新的电角度零位配置；失败时撤销电流并锁存原因。

### 4.4 `motor_config_store`

- 保存带 magic、版本号和 CRC32 的校准配置。
- 校验配置完整性和参数范围。
- 只允许在 PWM 关闭、驱动禁止和快速控制停止时擦写 Flash。
- 链接脚本和 Keil IROM 范围排除 STM32H743 最后一个 128 KB Flash 扇区 `0x081E0000～0x081FFFFF`，应用程序 IROM 长度相应限制为 `0x001E0000`，防止程序覆盖校准数据。

### 4.5 `motor_control`

- 编排模式、启动、停止、校准和故障状态。
- 在编码器模式中取得单次电角度快照，并将同一角度同时传给 Park 与反 Park。
- 继续接受外部 `Id_ref/Iq_ref`，不在电流环内部写死电流命令。
- 为后续速度 PI 输出 `Iq_ref` 保持稳定接口。

## 5. BiSS-C 帧读取与发布

SPI4 首次调试参数为：

```text
主机模式
8 bit 数据宽度
MSB first
CPOL = 1
CPHA = 0（第一边沿/下降沿采样）
软件 NSS
初始时钟约 1 MHz
```

每次读取产生 48 个时钟，以覆盖完整 BiSS-C 帧和必要余量。SPI发送寄存器写入的虚拟数据固定为零以持续产生时钟，但 PE6 不使用 SPI MOSI 复用输出，而由 GPIO锁定为低电平。

编码器本身的返回延迟约为 170 ns，板上还叠加 U27/U16 数字隔离器、MAX14783 和线缆传播延迟。1 MHz 时钟在编码器上升沿更新数据后提供约 500 ns 到下一下降采样沿，适合作为首轮保守配置；未经示波器确认下降沿前的数据建立时间和 CRC 错误率，不得直接恢复 SPI4 当前约 3.75 MHz 的配置。

解析器不得假设位置字段永远位于固定字节偏移。它应依据 ACK/Start/CDS 定位有效载荷，并验证：

- ACK 长度和 Start/CDS 结构合理。
- 17 位位置没有越界。
- Error 位表示位置有效。
- Warning 位被记录。
- 接收 CRC 与根据位置和状态重新计算的反相 CRC6 一致。

单帧失败时不覆盖上一帧有效角度。新数据发布采用短临界区或序号一致性方案，确保控制中断不会读到撕裂的数据结构。

## 6. 实时调度

不得把阻塞式 `HAL_SPI_TransmitReceive`、延时或日志放进 TIM8/ADC 快速中断。

目标调度为：

```text
TIM8 更新，10 kHz
    ├─ SPI4 空闲时启动下一次非阻塞读取
    └─ 执行现有快速模式调度

SPI4 DMA完成回调
    ├─ 结束本帧
    ├─ 解析与校验
    └─ 发布最新有效角度

ADC 注入完成，10 kHz
    ├─ 读取 IA/IB
    ├─ 获取一次编码器角度快照
    ├─ Clarke/Park
    ├─ Id/Iq PI
    ├─ 反 Park
    └─ SVPWM
```

电流环使用最近一次完整有效帧，绝不等待 SPI。允许使用上一控制周期完成的角度，初始低速阶段该固定延迟可接受；后续提高转速前，再通过提高 SPI4 时钟、测量固定延迟或增加角度预测补偿降低相位误差。

工程当前没有启用 Cortex-M7 数据缓存；SPI4 DMA 收发缓冲区放入 DMA 可访问的 AXI SRAM。若后续启用 D-Cache，必须把缓冲区放入不可缓存区域，或在传输前后执行正确的 Cache clean/invalidate。

## 7. 编码器角度与 FOC

机械角换算：

```c
mechanical_angle_pu = (float)position_raw / 131072.0f;
```

电角度换算：

```c
electrical_angle_pu = WrapToOne(
    encoder_direction *
    pole_pairs *
    (mechanical_angle_pu - electrical_zero_pu));
```

其中 `pole_pairs = 10`。极对数、方向和零位均来自集中配置，不在坐标变换函数中硬编码。

编码器电流模式的控制链为：

```text
IA/IB -> Clarke -> Park(theta_encoder) -> Id/Iq
Id_ref/Iq_ref -> Current PI -> Ud/Uq
Ud/Uq -> Inverse Park(theta_encoder) -> SVPWM -> TIM8
```

同一次 ADC 回调中必须锁存一个 `theta_encoder` 局部快照，Park 和反 Park 都使用该快照。

## 8. 电角度按需校准

校准不在每次上电自动运行，而由显式 API 或调试请求触发。保存配置有效时，上电直接加载；无有效配置时仅禁止编码器电流模式，不影响其他模式。

校准步骤：

1. 停止正常控制，关闭 PWM，并完成电流零点校准。
2. 连续检查 SPI4 帧、CRC 和 Error 状态。
3. 启动 PWM，在 200 ms 内将 `Id_ref` 从 0 A 斜坡增加到 0.2 A，`Iq_ref` 保持 0 A，定子电角度固定为 0 pu。
4. 等待 500 ms，在随后 128 个有效编码器样本中做环形平均；样本环形峰峰值默认不得超过 128 count。
5. 在 200 ms 内把定子电角度从 0 pu 缓慢推进到 `+0.1 pu`，读取机械角最短增量。增量绝对值必须处于 256～4096 count；其符号用于确定编码器方向。
6. 将定子电角度缓慢退回 0 pu，再次等待 500 ms 并平均 128 个有效样本，计算 `electrical_zero_raw`。
7. 撤销对齐电流、停止 PWM，清空电流 PI 和校准状态，把方向和零位写入保留 Flash 扇区。

校准对齐电流的硬上限为 0.5 A。编码器帧失败、电流异常、位置波动过大、方向不可判定或状态机超时均导致校准失败，并保证最终 PWM 关闭。

## 9. 电流命令与未来速度环接口

编码器电流模式继续使用物理量单位明确的命令：

```c
MotorControl_SetEncoderCurrentCommand(float id_ref_a,
                                      float iq_ref_a);
```

第一轮硬件验证从 `Id_ref = 0 A`、`Iq_ref = 0.1 A` 开始，依次尝试 0.2 A、0.3 A；确认电角度方向、电流反馈和转矩方向正确后，才允许逐步提高，初期不得超过已经在角度开环电流模式中验证的 0.8 A。

后续速度环数据链为：

```text
SPI4 机械角 -> 跨零速度估算 -> 速度滤波
速度目标 - 速度反馈 -> 速度 PI -> Iq_ref
Iq_ref -> 本设计的编码器角度电流闭环
```

因此本阶段不创建位置控制器，也不让编码器模块依赖未来的速度控制器。

## 10. 模式切换

- 电压开环与角度开环电流闭环继续沿用当前已验证的切换逻辑。
- 编码器通信可在其他模式下后台运行并提供调试观测，但编码器错误不得破坏这两个模式。
- 切入编码器模式前先验证数据新鲜度和校准配置，再用当前电流反馈对 PI 做无扰初始化。
- 切出编码器模式时清除编码器模式专用状态，但不清除已保存校准配置。
- 编码器模式运行中禁止切换角度源；角度源改变必须在控制周期边界完成。

## 11. 故障处理

新增故障或拒绝原因包括：

- 编码器 SPI 传输超时或忙状态卡死。
- ACK/Start/CDS 帧结构错误。
- CRC 连续失败。
- 编码器 Error 状态有效。
- 最新有效角度超过允许的数据年龄。
- 没有有效电角度校准配置。
- 对齐校准失败。
- Flash 配置读取、校验或写入失败。

编码器通信连续 32 帧有效后才进入 ready。单次帧错误只丢弃当前帧并沿用上一有效帧；编码器模式中，连续 10 个控制周期没有新有效角度（默认 1 ms），或者 SPI4 DMA 忙状态连续跨越 2 个控制周期，关闭 PWM、禁止驱动并锁存故障。Warning 状态记录到调试信息，短时 Warning 不直接停机。编码器错误在其他两个模式中只统计，不触发关断。

原有 ADC 越界、软件过流、控制数学异常和 DRV8323 故障处理保持不变。

## 12. 调试可观测性

扩展 `g_motor_control_debug`，至少包含：

- SPI4 最近 6 字节原始帧。
- ACK、Start、CDS、Position、Error、Warning、接收 CRC 和计算 CRC。
- 有效帧、CRC 错误、帧错误、SPI 错误和超时计数。
- 最近有效帧年龄和通信忙状态。
- 17 位原始机械位置、机械角 pu、电角度 pu。
- 编码器方向、零位、极对数和校准有效标志。
- 校准状态、稳定度、采样数量和失败原因。
- 当前角度源、模式、`Id/Iq`、`Id_ref/Iq_ref`、`Ud/Uq` 和故障码。

快速中断内禁止 `printf`、UART 阻塞发送和 Flash 擦写。

## 13. 验证计划

### 13.1 主机侧测试

- CRC6 已知向量与反相规则。
- 正常 17 位帧解析。
- ACK、Start、CDS 错位拒绝。
- Error、Warning 和 CRC 错误处理。
- 位置 0、131071 及机械角回绕。
- 10 对极电角度换算、方向和零位。
- 发布快照一致性和旧数据超时。
- 模式切换条件和编码器故障隔离。
- 校准环形平均、稳定度和失败路径。
- Flash 配置 magic、版本、范围和 CRC32 校验。

### 13.2 工程验证

1. Keil 全量编译为 0 error、0 warning。
2. 回归电压开环实机运行。
3. 回归角度开环电流闭环实机运行。
4. 不接母线，验证 PE6 恒低、PE2 空闲高和约 1 MHz 时钟。
5. 手动转动电机轴，确认 SPI4 原始帧、CRC、17 位位置和回绕连续。
6. 限流供电，使用 0.2 A 执行按需对齐校准。
7. 断电重启，验证保存配置加载和 CRC32。
8. 以 `Iq_ref = 0.1 A` 进入编码器角度电流模式。
9. 依次验证正负 `Iq_ref`、转矩方向、`Id` 接近零和 `Iq` 跟踪。
10. 在三种模式之间安全切换，确认任一新功能不会破坏原模式。

## 14. 对 F407 实现的取舍

保留：

- SPI2/`encoder2` 为电机轴角度来源的职责，在 H7 映射为 SPI4/ENC_01。
- 17 位单圈位置和 10 对极换算概念。
- 使用真实电角度参与电流环的总体目标。

重写：

- 阻塞式读取及前后 100 us 忙等。
- 两个编码器共用全局缓冲区。
- 固定移位提取位置且不校验 CRC。
- 在 ADC 快速中断中连续阻塞读取两个编码器。
- `ZEROANGLE` 和方向散落硬编码。
- 编码器数据无有效期、无错误累计、无故障隔离。

本设计不移植 F407 的 `positionloop()`、位置 PID 或未经验证的速度环参数。

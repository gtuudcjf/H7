# H7 Open-Loop Motor Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a documented, testable open-loop d/q voltage controller that drives the existing TIM8 three-phase PWM in the H7 CubeMX project.

**Architecture:** The pure control path is `open_loop -> svpwm -> pwm_3ph`. `motor_control` owns the fast-tick orchestration and exposes a stable command interface for future current and speed loops. The TIM8 adaptation stays separate from all control math.

**Tech Stack:** C99, STM32H7 HAL, existing CubeMX/MDK-ARM project, host-side C unit-test harness when a C compiler is available.

**Spec:** `docs/superpowers/specs/2026-09-09-h7-open-loop-design.md`

## Global Constraints

- Do not change `emptytest.ioc` or assume a BKIN input.
- Keep all new application code under `Core/Inc/motor` and `Core/Src/motor`.
- Do not perform SPI, UART, or delay operations from `MotorControl_FastTick()`.
- The PWM adapter owns TIM8 register/HAL access; the SVPWM module is hardware independent.
- Use a low initial normalized q-axis voltage and low electrical frequency only as an example command; board-specific limits remain explicit configuration values.
